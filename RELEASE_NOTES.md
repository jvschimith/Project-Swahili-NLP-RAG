# Release Notes

## v2.1.1-alpha

**Release type:** Internal/local alpha release  
**Purpose:** Establish a clean release baseline without changing product scope, API routes, or database schema.

### Supported In This Alpha

- Core Swahili linguistic domain modeling already present in the repository
- Lexical lookup, dictionary-oriented access, and morphology-related analysis flows
- Bantu noun-class classification and morphological root extraction
- FastAPI and Streamlit local development workflows
- Existing Swahili news analysis workflows for internal evaluation

### Experimental

- URL-based article fetching and downstream analysis quality across external sites
- Batch processing and research/export workflows
- Integration completeness across all repository modules
- Ongoing lexeme-first domain evolution alongside legacy compatibility models

### Intentionally Out Of Scope

- API route changes
- Database schema or migration changes
- Public production-readiness claims
- Product-scope expansion beyond the current repository capabilities

### Notes

- This release standardizes repository-facing version references to `v2.1.1-alpha`.
- It is intended as an internal checkpoint for stabilization and documentation alignment.
