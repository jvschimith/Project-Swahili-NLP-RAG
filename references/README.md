# Local linguistic references

This directory may contain private reference works used to derive and verify
linguistic rules during development. Copyrighted books and extracted full text
are not distributed and are ignored by Git (`references/*.pdf` and
`references/private/`). The application and tests must run without them.

Tracked project material may contain bibliographic provenance, concise factual
rule descriptions, and independently created examples. It must not reproduce
chapters, dialogues, exercises, vocabulary lists, scans, or substantial quoted
passages.
